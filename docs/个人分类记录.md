# 个人分类记录

本文记录从系统默认分类中移除的个人分类，避免后续维护默认配置时误加回来。

这些分类不再写入 `src/features/ledger/default-categories.ts`。如果某个账本需要使用，可在应用的分类管理中手动创建。

## 支出分类

| 大类 | 个人小类 |
| --- | --- |
| 餐饮 | 交家伙食费、跟朋友吃饭、上班带吃的 |
| 娱乐 | 打彩票玩、跟朋友喝酒 |
| 投资 | 移民相关 |
| 人情 | 随礼 |
| 生意 | 闲鱼服务 |

## 收入分类

| 分类 | 类型 |
| --- | --- |
| 生小孩随礼 | 收入 |
| 结婚随礼 | 收入 |
| 家人给的 | 收入 |

## 维护规则

- `default-categories.ts` 只保留适合新用户的通用系统分类。
- 个人分类只在确实需要的账本中手动添加。
- 修改默认分类不会自动删除已有账本中的分类。
